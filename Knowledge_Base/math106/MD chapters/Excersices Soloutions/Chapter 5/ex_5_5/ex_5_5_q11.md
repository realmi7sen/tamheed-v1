## Problem
Find the arc length of the graph of the equation from $A$ to $B$.
$30xy^3 - y^8 = 15$; $A(\frac{8}{15}, 1)$, $B(\frac{271}{240}, 2)$

## Rule Used
Definition 5.15 (Arc length $L_c^d$ with respect to $y$)

## Solution
**Step 1 — Solve the equation for $x = g(y)$**
$$30xy^3 = y^8 + 15$$
$$x = \frac{y^8}{30y^3} + \frac{15}{30y^3} = \frac{1}{30}y^5 + \frac{1}{2}y^{-3}$$

**Step 2 — Find the derivative $g'(y)$**
$$g'(y) = \frac{5}{30}y^4 - \frac{3}{2}y^{-4} = \frac{1}{6}y^4 - \frac{3}{2}y^{-4}$$

**Step 3 — Construct the integrand $\sqrt{1 + [g'(y)]^2}$**
$$[g'(y)]^2 = \left(\frac{1}{6}y^4 - \frac{3}{2}y^{-4}\right)^2 = \frac{1}{36}y^8 - 2\left(\frac{1}{6}\right)\left(\frac{3}{2}\right) + \frac{9}{4}y^{-8} = \frac{1}{36}y^8 - \frac{1}{2} + \frac{9}{4}y^{-8}$$
Add 1 to complete the square with a positive middle term:
$$1 + [g'(y)]^2 = 1 + \frac{1}{36}y^8 - \frac{1}{2} + \frac{9}{4}y^{-8} = \frac{1}{36}y^8 + \frac{1}{2} + \frac{9}{4}y^{-8} = \left(\frac{1}{6}y^4 + \frac{3}{2}y^{-4}\right)^2$$
$$\sqrt{1 + [g'(y)]^2} = \sqrt{\left(\frac{1}{6}y^4 + \frac{3}{2}y^{-4}\right)^2} = \frac{1}{6}y^4 + \frac{3}{2}y^{-4}$$

**Step 4 — Set up and evaluate the definite integral**
The interval spans from $y = 1$ to $y = 2$.
$$L_1^2 = \int_{1}^{2} \left( \frac{1}{6}y^4 + \frac{3}{2}y^{-4} \right) dy$$
$$L_1^2 = \left[ \frac{1}{30}y^5 - \frac{1}{2}y^{-3} \right]_1^2$$
$$= \left( \frac{32}{30} - \frac{1}{2(8)} \right) - \left( \frac{1}{30} - \frac{1}{2} \right) = \left( \frac{16}{15} - \frac{1}{16} \right) - \left( \frac{1}{30} - \frac{1}{2} \right)$$
Find a common denominator, which is 240:
$$= \left( \frac{256}{240} - \frac{15}{240} \right) - \left( \frac{8}{240} - \frac{120}{240} \right) = \frac{241}{240} - \left( -\frac{112}{240} \right) = \frac{353}{240}$$

## Answer
$\frac{353}{240}$

## Check by Differentiation
Differentiating $\frac{1}{30}y^5 - \frac{1}{2}y^{-3}$ gives $\frac{1}{6}y^4 + \frac{3}{2}y^{-4}$. Verified.
