## Problem
Let $R$ be the region bounded by the graphs of the equations. Set up an integral that can be used to find the volume of the solid generated if $R$ is revolved about the given line. Use cylindrical shells.
$y = x^2$, $y = 4$
(a) $y = 4$
(b) $y = 5$
(c) $x = 2$
(d) $x = -3$

## Rule Used
Guidelines for Finding the Volume of a Solid of Revolution Using Cylindrical Shells 5.12

## Solution
**Step 1 — Understand the Region**
The region $R$ is bounded above by $y = 4$ and below by $y = x^2$. 
The intersection points are $x^2 = 4 \implies x = \pm 2$. Thus, $x \in [-2, 2]$ and $y \in [0, 4]$.

**Part (a) — Revolving about $y = 4$**
Revolving about a horizontal line using shells requires horizontal rectangles of thickness $dy$.
- **Radius:** Distance from generic $y$ to $y = 4$, which is $(4 - y)$.
- **Altitude:** Right boundary minus left boundary. Rewrite $y = x^2$ as $x = \pm\sqrt{y}$. Altitude $= \sqrt{y} - (-\sqrt{y}) = 2\sqrt{y}$.
- **Integral:**
  $$V = \int_{0}^{4} 2\pi (4 - y)(2\sqrt{y}) dy = \int_{0}^{4} 4\pi (4 - y)\sqrt{y} dy$$

**Part (b) — Revolving about $y = 5$**
Revolving about a horizontal line requires horizontal rectangles of thickness $dy$.
- **Radius:** Distance from generic $y$ to $y = 5$, which is $(5 - y)$.
- **Altitude:** $\sqrt{y} - (-\sqrt{y}) = 2\sqrt{y}$.
- **Integral:**
  $$V = \int_{0}^{4} 2\pi (5 - y)(2\sqrt{y}) dy = \int_{0}^{4} 4\pi (5 - y)\sqrt{y} dy$$

**Part (c) — Revolving about $x = 2$**
Revolving about a vertical line using shells requires vertical rectangles of thickness $dx$.
- **Radius:** Distance from generic $x$ in $[-2, 2]$ to the line $x = 2$, which is $(2 - x)$.
- **Altitude:** Upper boundary minus lower boundary, which is $(4 - x^2)$.
- **Integral:**
  $$V = \int_{-2}^{2} 2\pi (2 - x)(4 - x^2) dx$$

**Part (d) — Revolving about $x = -3$**
Revolving about a vertical line requires vertical rectangles of thickness $dx$.
- **Radius:** Distance from the line $x = -3$ to a generic $x$ in $[-2, 2]$, which is $x - (-3) = x + 3$.
- **Altitude:** $(4 - x^2)$.
- **Integral:**
  $$V = \int_{-2}^{2} 2\pi (x + 3)(4 - x^2) dx$$

## Answer
(a) $\int_{0}^{4} 4\pi (4 - y)\sqrt{y} dy$
(b) $\int_{0}^{4} 4\pi (5 - y)\sqrt{y} dy$
(c) $\int_{-2}^{2} 2\pi (2 - x)(4 - x^2) dx$
(d) $\int_{-2}^{2} 2\pi (x + 3)(4 - x^2) dx$
