## Problem
Find the area of the surface generated by revolving the curve about the x-axis.
$x = t^2, y = t - \frac{1}{3}t^3$; $0 \le t \le 1$

## Rule Used
Theorem 9.8 (Surface Area for Revolution about the x-axis)

## Solution
**Step 1 — Find the derivatives $dx/dt$ and $dy/dt$**
$$\frac{dx}{dt} = 2t$$
$$\frac{dy}{dt} = 1 - t^2$$

**Step 2 — Construct the arc length differential $ds$**
$$\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 = (2t)^2 + (1 - t^2)^2 = 4t^2 + (1 - 2t^2 + t^4) = 1 + 2t^2 + t^4 = (1 + t^2)^2$$
$$ds = \sqrt{(1 + t^2)^2} dt = (1 + t^2) dt$$

**Step 3 — Set up the surface area integral**
$$S = \int_{0}^{1} 2\pi y ds = \int_{0}^{1} 2\pi \left( t - \frac{1}{3}t^3 \right) (1 + t^2) dt$$

**Step 4 — Expand and evaluate the integral**
$$S = 2\pi \int_{0}^{1} \left( t + t^3 - \frac{1}{3}t^3 - \frac{1}{3}t^5 \right) dt = 2\pi \int_{0}^{1} \left( t + \frac{2}{3}t^3 - \frac{1}{3}t^5 \right) dt$$
$$S = 2\pi \left[ \frac{t^2}{2} + \frac{2}{12}t^4 - \frac{1}{18}t^6 \right]_0^1$$
$$S = 2\pi \left( \frac{1}{2} + \frac{1}{6} - \frac{1}{18} \right) = 2\pi \left( \frac{9}{18} + \frac{3}{18} - \frac{1}{18} \right) = 2\pi \left( \frac{11}{18} \right) = \frac{11\pi}{9}$$

## Answer
$\frac{11\pi}{9}$

## Check by Differentiation
$\frac{d}{dt} \left[ \frac{t^2}{2} + \frac{1}{6}t^4 - \frac{1}{18}t^6 \right] = t + \frac{2}{3}t^3 - \frac{1}{3}t^5$. Verified.
