## Problem
Find the arc length of the graph of the equation from $A$ to $B$.
$y = \frac{2}{3}x^{2/3}$; $A(1, \frac{2}{3})$, $B(8, \frac{8}{3})$

## Rule Used
Definition 5.14 (Arc length $L_a^b$ with respect to $x$)

## Solution
**Step 1 — Find the derivative $f'(x)$**
Given $f(x) = \frac{2}{3}x^{2/3}$, the derivative is:
$$f'(x) = \frac{2}{3} \cdot \frac{2}{3}x^{-1/3} = \frac{4}{9}x^{-1/3}$$

**Step 2 — Construct the integrand $\sqrt{1 + [f'(x)]^2}$**
$$[f'(x)]^2 = \left(\frac{4}{9}x^{-1/3}\right)^2 = \frac{16}{81}x^{-2/3}$$
$$1 + [f'(x)]^2 = 1 + \frac{16}{81x^{2/3}} = \frac{81x^{2/3} + 16}{81x^{2/3}}$$
$$\sqrt{1 + [f'(x)]^2} = \sqrt{\frac{81x^{2/3} + 16}{81x^{2/3}}} = \frac{\sqrt{81x^{2/3} + 16}}{9x^{1/3}}$$

**Step 3 — Set up the definite integral**
The x-coordinates of the endpoints are $a = 1$ and $b = 8$.
$$L_1^8 = \int_{1}^{8} \frac{\sqrt{81x^{2/3} + 16}}{9x^{1/3}} dx$$

**Step 4 — Evaluate the integral using substitution**
Let $u = 81x^{2/3} + 16$.
$$du = 81 \cdot \frac{2}{3}x^{-1/3} dx = 54x^{-1/3} dx \implies \frac{du}{54} = \frac{1}{x^{1/3}} dx$$
Change the limits of integration:
When $x = 1$, $u = 81(1)^{2/3} + 16 = 81 + 16 = 97$.
When $x = 8$, $u = 81(8)^{2/3} + 16 = 81(4) + 16 = 324 + 16 = 340$.
Substitute into the integral:
$$L_1^8 = \int_{97}^{340} \frac{\sqrt{u}}{9} \left( \frac{du}{54} \right) = \frac{1}{486} \int_{97}^{340} u^{1/2} du$$
$$= \frac{1}{486} \left[ \frac{2}{3}u^{3/2} \right]_{97}^{340} = \frac{2}{1458} \left( 340^{3/2} - 97^{3/2} \right) = \frac{1}{729} \left( 340^{3/2} - 97^{3/2} \right)$$

## Answer
$\frac{1}{729} \left( 340^{3/2} - 97^{3/2} \right)$

## Check by Differentiation
Verify the antiderivative using the chain rule on $G(u) = \frac{1}{729} u^{3/2}$ where $u = 81x^{2/3} + 16$:
$G'(x) = \frac{1}{729} \cdot \frac{3}{2} (81x^{2/3} + 16)^{1/2} \cdot \left(54x^{-1/3}\right) = \frac{81}{729} (81x^{2/3} + 16)^{1/2} x^{-1/3} = \frac{1}{9x^{1/3}} \sqrt{81x^{2/3} + 16}$. Verified.
