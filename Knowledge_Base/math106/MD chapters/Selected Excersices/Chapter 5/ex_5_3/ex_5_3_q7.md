## Problem
Sketch the region $R$ bounded by the graphs of the equations, and find the volume of the solid generated if $R$ is revolved about the indicated axis. Use cylindrical shells.
$y = x^2$, $y^2 = 8x$; y-axis

## Rule Used
Guidelines for Finding the Volume of a Solid of Revolution Using Cylindrical Shells 5.12

## Solution
**Step 1 — Find points of intersection**
Set the equations equal to each other to find the bounds for $x$.
$$y = x^2 \implies (x^2)^2 = 8x$$
$$x^4 = 8x$$
$$x^4 - 8x = 0$$
$$x(x^3 - 8) = 0$$
The intersection points occur at $x = 0$ and $x = 2$.

**Step 2 — Identify the components of the shell**
Revolving about the y-axis uses vertical rectangles with thickness $dx$.
The radius of the shell is $x$.
The upper boundary curve is $y = \sqrt{8x} = 2\sqrt{2x}$ and the lower boundary curve is $y = x^2$.
The altitude is the difference: $2\sqrt{2x} - x^2 = 2\sqrt{2}x^{1/2} - x^2$.

**Step 3 — Set up the integral for volume**
$$V = \int_{0}^{2} 2\pi x \left( 2\sqrt{2}x^{1/2} - x^2 \right) dx$$
$$V = 2\pi \int_{0}^{2} \left( 2\sqrt{2}x^{3/2} - x^3 \right) dx$$

**Step 4 — Evaluate the definite integral**
$$V = 2\pi \left[ 2\sqrt{2} \left(\frac{2}{5}\right) x^{5/2} - \frac{x^4}{4} \right]_0^2$$
$$V = 2\pi \left( \frac{4\sqrt{2}}{5} (2)^{5/2} - \frac{2^4}{4} \right)$$
$$V = 2\pi \left( \frac{4\sqrt{2}}{5} (4\sqrt{2}) - \frac{16}{4} \right)$$
$$V = 2\pi \left( \frac{32}{5} - 4 \right) = 2\pi \left( \frac{32}{5} - \frac{20}{5} \right)$$
$$V = 2\pi \left( \frac{12}{5} \right) = \frac{24\pi}{5}$$

## Answer
$\frac{24\pi}{5}$

## Check by Differentiation
$\frac{d}{dx} \left[ 2\pi \left( \frac{4\sqrt{2}}{5} x^{5/2} - \frac{x^4}{4} \right) \right] = 2\pi \left( 2\sqrt{2}x^{3/2} - x^3 \right)$. Verified.
