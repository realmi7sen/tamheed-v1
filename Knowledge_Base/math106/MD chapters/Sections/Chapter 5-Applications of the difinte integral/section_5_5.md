## Definitions
* **Definition 5.14**
  If a function $f$ is smooth on the interval $[a, b]$, the arc length of the graph of $f$ from the point $A(a, f(a))$ to the point $B(b, f(b))$ is given by[cite: 1]:
  $$L_a^b = \int_{a}^{b} \sqrt{1 + [f'(x)]^2} dx$$
* **Definition 5.15**
  If an equation is written as $x = g(y)$, and $g$ is a smooth function on the interval $[c, d]$, the arc length of the graph of $g$ from $(g(c), c)$ to $(g(d), d)$ is given by[cite: 1]:
  $$L_c^d = \int_{c}^{d} \sqrt{1 + [g'(y)]^2} dy$$
* **Definition 5.16**
  Assume that $f$ is smooth on $[a, b]$[cite: 1]. The arc length function $s$ for the graph of $f$ on the interval $[a, b]$ is defined by[cite: 1]:
  $$s(x) = \int_{a}^{x} \sqrt{1 + [f'(t)]^2} dt$$
  for $a \le x \le b$[cite: 1].
* **Definition 5.19**
  If $f$ is a smooth function and $f(x) \ge 0$ on the interval $[a, b]$, then the area $S$ of the surface of revolution generated by revolving the graph of $f$ about the x-axis is[cite: 1]:
  $$S = \int_{a}^{b} 2\pi f(x) \sqrt{1 + [f'(x)]^2} dx$$
  *Extension for negative functions:* If $f$ is negative for some $x$ in $[a, b]$, the surface area $S$ can be found using[cite: 1]:
  $$S = \int_{a}^{b} 2\pi |f(x)| \sqrt{1 + [f'(x)]^2} dx$$

## Theorems
* **Theorem 5.17**
  Suppose $f$ is smooth on $[a, b]$, and let $s$ be the arc length function for the graph of $y = f(x)$ on $[a, b]$[cite: 1]. If $\Delta x$ represents an increment in the variable $x$, then[cite: 1]:
  (i) $\frac{ds}{dx} = \sqrt{1 + [f'(x)]^2}$
  (ii) $ds = \sqrt{1 + [f'(x)]^2} \Delta x$

## Formulas
* **Surface Area $S$ of a Frustum of a Cone 5.18**
  The surface area of a frustum of a cone is given by[cite: 1]:
  $$S = 2\pi (\text{average radius}) (\text{slant height})$$

## Worked Examples
### Example 1
If $f(x) = 3x^{2/3} - 10$, find the arc length of the graph of $f$ from the point $A(8, 2)$ to $B(27, 17)$[cite: 1].

**Solution**
* **Step 1:** Calculate the derivative of $f(x)$[cite: 1].
  $$f'(x) = 2x^{-1/3} = \frac{2}{x^{1/3}}$$
* **Step 2:** Apply Definition (5.14) to set up the integral[cite: 1].
  $$L_8^{27} = \int_{8}^{27} \sqrt{1 + \left(\frac{2}{x^{1/3}}\right)^2} dx = \int_{8}^{27} \sqrt{1 + \frac{4}{x^{2/3}}} dx$$
  $$= \int_{8}^{27} \sqrt{\frac{x^{2/3} + 4}{x^{2/3}}} dx = \int_{8}^{27} \sqrt{x^{2/3} + 4} \frac{1}{x^{1/3}} dx$$
* **Step 3:** Use substitution to evaluate the integral. Let $u = x^{2/3} + 4$, which implies $du = \frac{2}{3}x^{-1/3} dx = \frac{2}{3}\frac{1}{x^{1/3}} dx$[cite: 1]. Introduce the factor $\frac{2}{3}$ into the integrand and compensate by multiplying the integral by $\frac{3}{2}$[cite: 1].
  $$L_8^{27} = \frac{3}{2} \int_{8}^{27} \sqrt{x^{2/3} + 4} \left(\frac{2}{3}\frac{1}{x^{1/3}}\right) dx$$
* **Step 4:** Calculate the new limits of integration[cite: 1].
  If $x = 8$, then $u = 8^{2/3} + 4 = 8$[cite: 1].
  If $x = 27$, then $u = 27^{2/3} + 4 = 13$[cite: 1].
* **Step 5:** Evaluate the definite integral with respect to $u$[cite: 1].
  $$L_8^{27} = \frac{3}{2} \int_{8}^{13} \sqrt{u} du = \left[ u^{3/2} \right]_8^{13} = 13^{3/2} - 8^{3/2} \approx 24.2$$

### Example 2
(a) Set up an integral for finding the arc length of the graph of the equation $y^3 - y - x = 0$ from $A(0, -1)$ to $B(6, 2)$[cite: 1].
(b) Approximate the integral in part (a) to at least four-decimal-place accuracy by using Simpson's rule (4.38)[cite: 1].

**Solution**
* **Step 1 (a):** Because the equation is not in the form $y = f(x)$, rewrite it as $x = y^3 - y$ and use formula (5.15) with $g(y) = y^3 - y$[cite: 1]. Using $c = -1$ and $d = 2$[cite: 1]:
  $$L_{-1}^2 = \int_{-1}^{2} \sqrt{1 + (3y^2 - 1)^2} dy = \int_{-1}^{2} \sqrt{9y^4 - 6y^2 + 2} dy$$
* **Step 2 (b):** Apply Simpson's rule computationally[cite: 1]. Doubling $n$ successively yields approximately $8.7250$ for $n = 8, 16,$ and $32$[cite: 1].
  $$\int_{-1}^{2} \sqrt{9y^4 - 6y^2 + 2} dy \approx 8.7250$$

### Example 3
Approximate the arc length of the graph of the equation $y = x^3 + 2x$ from $A(1, 3)$ to $B(1.2, 4.128)$ by (a) differentials at $x_0 = 1$, (b) the line segment from $A$ to $B$, and (c) the trapezoidal rule applied to the definite integral from Definition (5.15) with $n = 10$ and $n = 20$[cite: 1].

**Solution**
* **Step 1 (a):** Let $g(x) = x^3 + 2x$, so $g'(x) = 3x^2 + 2$[cite: 1]. By Theorem (5.17)(ii), $ds = \sqrt{1 + (3x^2 + 2)^2} \Delta x$[cite: 1].
  Let $x = 1$ and $\Delta x = 0.2$[cite: 1]:
  $$\Delta s \approx ds = \sqrt{1 + 5^2}(0.2) = \sqrt{26}(0.2) \approx 1.01980$$
* **Step 2 (b):** Use the distance formula for the line segment[cite: 1].
  $$d(A, B) = \sqrt{(1.2 - 1)^2 + (4.128 - 3)^2} = \sqrt{(0.2)^2 + (1.128)^2} \approx 1.14559$$
* **Step 3 (c):** Use the trapezoidal rule for $n = 10$, where $\Delta x = \frac{1.2 - 1}{10} = 0.02$[cite: 1].
  $$T_{10} \approx 1.456709 \quad \text{and} \quad T_{20} \approx 1.456811$$

### Example 4
The graph of $y = \sqrt{x}$ from $(1, 1)$ to $(4, 2)$ is revolved about the x-axis[cite: 1]. Find the area of the resulting surface[cite: 1].

**Solution**
* **Step 1:** Apply Definition (5.19)[cite: 1].
  $$S = \int_{1}^{4} 2\pi y dx = \int_{1}^{4} 2\pi x^{1/2} \sqrt{1 + \left(\frac{1}{2x^{1/2}}\right)^2} dx$$
* **Step 2:** Simplify the integrand and evaluate[cite: 1].
  $$S = \int_{1}^{4} 2\pi x^{1/2} \sqrt{\frac{4x + 1}{4x}} dx = \pi \int_{1}^{4} \sqrt{4x + 1} dx$$
  $$= \frac{\pi}{6} \left[ (4x + 1)^{3/2} \right]_1^4 = \frac{\pi}{6} (17^{3/2} - 5^{3/2}) \approx 30.85 \text{ square units}$$
